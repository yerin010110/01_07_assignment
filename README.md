YOLOv8 기반 도로 표지판 객체 탐지 실습
1. 과제 개요

본 과제는 객체 탐지(Object Detection) 분야에서 널리 사용되는 YOLOv8 모델을 활용하여 도로 표지판을 탐지하는 모델을 학습하고, 학습된 모델을 이용해 실제 이미지에 대한 객체 탐지를 수행하는 것을 목표로 합니다.
Kaggle에서 제공하는 Road Sign Detection 데이터셋을 사용하여 데이터셋 준비, 모델 학습, 추론(predict), 결과 시각화까지 객체 탐지의 전체 과정을 Google Colab 환경에서 실습하였습니다.
또한 실습 결과를 GitHub에 정리함으로써, 모델 학습 및 추론 과정의 재현성과 결과 해석 과정을 명확히 기록하고자 하였습니다.

데이터셋 출처: https://www.kaggle.com/datasets/andrewmvd/road-sign-detection

데이터셋 구성: 총 877장의 이미지, 4개 클래스의 도로 표지판 데이터

2. 실습 목표

본 실습의 구체적인 목표는 다음과 같습니다.

첫째, YOLO 형식의 객체 탐지 데이터셋 구조를 이해하고, 이미지와 라벨 데이터를 학습에 적합한 형태로 구성합니다.
둘째, YOLOv8 모델을 활용하여 객체 탐지 모델을 직접 학습함으로써, 딥러닝 기반 객체 탐지 모델의 학습 과정을 이해합니다.
셋째, 학습된 모델을 이용해 도로 표지판 이미지에 대한 객체 탐지를 수행하고, 탐지 결과를 시각적으로 확인합니다.
넷째, 탐지 결과를 분석하고 이를 문서로 정리하여 객체 탐지 모델의 성능과 한계를 파악합니다.

3. 데이터셋 준비
3.1 데이터 다운로드

본 실습에서는 Kaggle API를 사용하여 Road Sign Detection 데이터셋을 다운로드하였습니다.
Kaggle API 인증을 위해 kaggle.json 파일을 설정하였으며, Colab 환경에서 데이터셋을 안정적으로 다운로드할 수 있도록 구성하였습니다.

3.2 데이터 구조 정리

YOLOv8 모델 학습을 위해 데이터셋을 YOLO 형식에 맞게 정리하였습니다.
이미지 파일과 라벨 파일을 각각 images, labels 디렉터리로 분리하고, 학습용(train)과 검증용(val) 데이터로 구분하였습니다.

road_sign_yolo/
├── images/
│   ├── train/
│   └── val/
├── labels/
│   ├── train/
│   └── val/
└── data.yaml


이와 같은 구조를 통해 YOLOv8이 데이터 경로를 명확히 인식할 수 있도록 하였습니다.

3.3 data.yaml 파일 작성

YOLOv8 학습을 위해 이미지 및 라벨 경로, 클래스 정보를 포함한 data.yaml 파일을 직접 작성하였습니다.
해당 파일에는 학습 및 검증 데이터 경로와 클래스 개수, 클래스 이름이 정의되어 있으며, 모델 학습 시 필수적으로 사용됩니다.

4. YOLOv8 모델 학습

본 실습에서는 YOLOv8 모델 중 경량 모델인 YOLOv8n을 사용하여 학습을 진행하였습니다.
학습은 Google Colab 환경에서 수행하였으며, GPU를 활용하여 학습 시간을 단축하였습니다.

주요 학습 설정은 다음과 같습니다.

사용 모델: YOLOv8n

Epoch 수: 20

입력 이미지 크기: 640

Optimizer 및 기타 하이퍼파라미터: 기본 설정 사용

학습 과정에서 loss 값이 점진적으로 감소하는 것을 확인하였으며, 이는 모델이 도로 표지판의 시각적 특징을 점차 학습하고 있음을 의미합니다.
학습이 완료된 후, 가장 성능이 우수한 가중치 파일이 자동으로 저장되었습니다.

> runs/road_sign_yolov8n/weights/best.pt

5. 객체 탐지 테스트

학습이 완료된 모델을 이용하여 도로 표지판 이미지에 대한 객체 탐지를 수행하였습니다.
YOLOv8의 predict() 기능을 사용하여 새로운 이미지에 대한 추론을 진행하였으며, 추론 결과는 이미지 파일 형태로 저장되었습니다.

탐지 결과 이미지는 다음 경로에 저장되었습니다.

> runs/road_sign_predict/


각 결과 이미지에는 모델이 탐지한 객체에 대해 바운딩 박스, 클래스 이름, 신뢰도(confidence score)가 함께 표시됩니다.

6. 결과 정리 및 분석
6.1 탐지 결과 시각화

탐지 결과 이미지를 Colab 환경에서 직접 출력하여 모델의 예측 결과를 시각적으로 확인하였습니다.
이를 통해 모델이 어떤 위치에 바운딩 박스를 생성했는지, 어떤 클래스로 분류했는지를 직관적으로 확인할 수 있었습니다.

6.2 탐지 결과 분석

객체 탐지 결과, 이미지 내에서 횡단보도(crosswalk) 표지판이 정확하게 탐지되었음을 확인하였습니다.
모델이 생성한 바운딩 박스는 실제 표지판 영역을 비교적 정확하게 감싸고 있으며, 높은 신뢰도로 예측이 이루어졌습니다.
이는 학습 과정에서 모델이 도로 표지판의 형태, 색상, 패턴과 같은 시각적 특징을 효과적으로 학습했음을 의미합니다.

다만, 일부 이미지에서는 배경이 복잡한 경우나 표지판이 작게 등장하는 경우 탐지 성능이 다소 저하될 가능성도 확인할 수 있었습니다.

7. 결론 및 고찰

본 실습을 통해 YOLOv8 기반 객체 탐지 모델의 데이터 준비, 학습, 추론, 결과 분석까지의 전 과정을 경험하였습니다.
단순히 모델을 사용하는 데 그치지 않고, 데이터 구조 설계와 결과 해석 과정을 직접 수행함으로써 객체 탐지 모델의 동작 원리를 보다 깊이 이해할 수 있었습니다.
향후 더 많은 데이터와 다양한 도로 환경을 포함한 학습을 진행한다면, 실제 교통 환경에서도 활용 가능한 객체 탐지 모델로 확장할 수 있을 것으로 판단됩니다.
